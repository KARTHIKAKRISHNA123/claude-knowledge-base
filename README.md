# Claude Knowledge Base

A personal knowledge repository containing reference materials, practice resources, guides, and learning documents related to **Claude AI, AI-assisted development, Cowork, and LLM-based workflows**.

## About

This repository serves as a centralized knowledge base for collecting and organizing useful learning resources related to:

- Claude AI
- Claude and LLM workflows
- Claude Cowork
- AI-assisted software development
- Prompting and AI productivity
- LLM tools and workflows
- Karpathy's LLM resources
- Practical guides and hands-on reference materials

The purpose of this repository is to keep important technical and learning resources available in one place for future reference, experimentation, and continuous learning.

## Purpose

This repository is maintained as a **personal technical knowledge base**.

The main goals are:

1. **Learn** — Collect useful technical resources while learning AI and LLM technologies.
2. **Practice** — Keep practical guides and exercises available for hands-on experimentation.
3. **Reference** — Use the repository as a quick reference when working on AI-related projects.
4. **Organize** — Keep scattered learning materials centralized and version-controlled.
5. **Build** — Apply the knowledge from these resources to real-world AI and software projects.

## Knowledge Management Approach

The repository follows a simple principle:

> **Learn → Practice → Build → Document → Reuse**

Instead of treating learning materials as one-time resources, this repository is intended to become a continuously evolving technical reference.
